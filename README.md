XCutors is a curated collection that bundles five different tools: four individual Roblox executors (Volt, Synapse Z, Potassium, Wave) and one universal loader program designed to manage and launch them.

### Why does my anticomponent flag the download?

Security software may sometimes incorrectly identify executor or loader programs as threats because they utilize techniques to interact with other running processes. These are typically false positives for this type of software.

### What is the universal loader for?

The universal loader (xcutorsLoader) provides a central interface to organize and quickly launch any of the four included executors. It simplifies the process of switching between different tools.

### Do I need to pay for each executor included?

The XCutors repository itself is a free collection. However, some of the individual executors included (like Synapse Z) are traditionally paid software elsewhere; this pack aims to provide accessible versions.

### Is using this package safe for my Roblox account?

Using any third-party executor against Roblox's Terms of Service carries a risk of account action. Use these tools with caution and at your own discretion.

### What is the password for the zip file?

The extraction password is provided clearly in the main repository README file. It is included to prevent casual automated scanning of the repository contents.

### Which Windows versions are supported?

The package is designed and tested for Windows 10 and Windows 11 desktop operating systems. Full functionality and compatibility may vary on older or non-standard Windows editions.

### How do I update the tools later?

You can return to this GitHub repository to download the latest release. Simply follow the same installation steps again, which will overwrite the old files.
